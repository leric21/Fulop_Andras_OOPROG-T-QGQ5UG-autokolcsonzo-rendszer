# Autókölcsönző Rendszer

## Projekt leírás

Ez a projekt egy egyszerű konzolos autókölcsönző rendszer Python nyelven megvalósítva.

A rendszer lehetővé teszi:
- autók bérlését
- bérlések lemondását
- aktuális bérlések listázását
- elérhető autók megtekintését

A projekt objektumorientált programozási elveket használ:
- absztrakt osztály
- öröklődés
- enkapszuláció
- hibakezelés

---

## Használt technológiák

- Python 3
